# Retail Performance Intelligence Hub

### Power BI Business Analytics Dashboard | Self-Initiated Portfolio Project

An interactive Power BI dashboard designed to analyze retail revenue, profitability, product performance, regional performance, and customer-segment contribution using a synthesized 2024–2025 dataset.

---

## 📊 Project Overview

This self-initiated portfolio project explores how retail transaction data can be transformed into an interactive business intelligence solution for performance monitoring and decision support.

The dashboard brings together revenue, profitability, product, regional, customer-segment, and operational analysis across four interactive Power BI pages.

### Project Details

| | |
|---|---|
| **Role** | Business Analytics Consultant |
| **Tools** | Power BI, Power Query, DAX, Excel |
| **Dataset** | Synthesized retail dataset |
| **Data Period** | 2024–2025 |
| **Orders** | 6,000 |
| **Customers** | 1,200 |
| **Products** | 80 |

---

## 🎯 Objectives

- Monitor overall retail business performance
- Analyze revenue and profitability trends
- Identify high- and low-performing products
- Compare regional performance
- Analyze customer-segment contribution
- Examine discount and profitability relationships
- Track operational KPIs
- Present insights through an executive-friendly dashboard

---

## 📑 Dashboard Pages

### 01 — Executive Dashboard

Provides a high-level view of overall business performance, including revenue, profit, profitability, orders, average order value, regional performance, category performance, and operational KPIs.

### 02 — Sales & Profitability

Analyzes sales and profitability drivers across time, customer segments, categories, subcategories, and orders.

### 03 — Product Intelligence

Examines product-level revenue, profit, profitability margins, discounts, and high- and low-performing products.

### 04 — Regional & Customer Intelligence

Explores regional performance, customer-segment contribution, segment mix, order behavior, and regional trends.
